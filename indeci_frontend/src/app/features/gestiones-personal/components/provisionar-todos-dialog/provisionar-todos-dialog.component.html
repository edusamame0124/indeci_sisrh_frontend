Provisionar para todos

Esta acción recalcula, para todos los empleados importados, los días que corresponden (30 × períodos ganados) y el saldo resultante. Los días gozados importados del Excel se conservan (no se reinician); si un empleado tiene adelanto sin período aún ganado, su saldo quedará negativo (deuda) hasta que el período venza. Cada empleado se procesa de forma independiente y trazable.

Sustento del lote El sustento es obligatorio.

Base normativa: D.Leg. 1405 y D.S. 013-2019-PCM.
